# E‑commerce Category Performance Analysis

Analysis of e‑commerce category performance with Python, Jupyter, and Tableau.

## Overview

This project explores how different product categories perform in an e‑commerce setting using Jupyter Notebooks for analysis and Tableau for interactive visualization.

## Objectives

- Analyze revenue and demand across categories  
- Understand item counts, unique orders, and average price  
- Evaluate delivery days and freight cost for operational efficiency  
- Identify:
  - Workhorse categories (high volume, high revenue)  
  - Premium categories (high price per order)  
  - Optimization opportunities (high freight or long delivery time)

## Repository Contents

- `notebooks/`  
  - Jupyter Notebook with data cleaning, feature engineering, and exploratory analysis
- `tableau/`

## Key Questions

- Which categories generate the most revenue and orders?  
- How do price, delivery time, and freight cost relate to performance?  
- Which categories show the best potential for margin improvement or customer experience gains?
